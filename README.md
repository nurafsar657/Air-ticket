# ✈️ Air Ticket Booking Interface

A modern, responsive, and user-friendly web interface designed for booking flight tickets effortlessly. Built with HTML5 and styled using Tailwind CSS.

---

## 🧐 Project Overview
This project serves as an intuitive digital form for flight reservations. It streamlines the user experience by organizing booking inputs into clean, visual sections—covering personal details, flight schedules, cabin class selection, add-on services, and special notes.

---

## 🛠️ Tech Stack
* **HTML5**: For semantic layout and structured form elements.
* **Tailwind CSS**: Utility-first CSS framework for custom gradients, grid systems, and modern visual design.

---

## ✨ Key Features
* **Personal Information**: Collects traveler's Full Name, Email, Phone Number, and Passenger Count.
* **Flight Details**: Inputs for Departure City, Destination City, Departure Date, and Return Date.
* **Travel Class Selection**: Custom styled radio options for Economy, Business, and First Class.
* **Additional Services**: Selectable add-ons for Meals, Extra Luggage, and Travel Insurance.
* **Special Requests**: Textarea for custom user instructions or accessibility needs.
* **Interactive UI**: Responsive layout with modern hover effects, focused input highlights, and gradient backgrounds.

---
